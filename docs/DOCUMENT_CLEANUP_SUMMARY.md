## 🎯 文档组织原则

### 单一真相源（Single Source of Truth）
- **测试相关的所有信息** → `UNIT_TEST_DESIGN.md`
- 避免信息分散在多个文档中
- 确保文档的一致性和可维护性

### 文档层次
```
项目根目录/
├── README.md              # 项目入口，快速了解
├── ARCHITECTURE.md        # 架构设计，理解系统
├── API_REFERENCE.md       # API 参考，开发查阅
└── UNIT_TEST_DESIGN.md    # 测试设计，测试指南 ⭐
```

### 文档职责
- **README.md**: 让新用户快速上手
- **ARCHITECTURE.md**: 帮助开发者理解系统设计
- **API_REFERENCE.md**: 提供详细的 API 使用说明
- **UNIT_TEST_DESIGN.md**: 指导测试开发和执行
